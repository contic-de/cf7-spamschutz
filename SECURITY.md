# Sicherheitshinweise

Eine Schwachstelle in diesem Projekt melden Sie bitte **nicht** als öffentliches Issue, sondern per E-Mail an
**info@contic.de** (Betreff: „Sicherheit: cf7-spamschutz“). Beschreiben Sie, was Sie gefunden haben, wie man es
nachstellt und welche Version betroffen ist. Wir antworten, sobald wir die Meldung gelesen haben, und nennen
dann einen Zeitplan; eine feste Frist sagen wir nicht zu.

*English:* Please report vulnerabilities by e-mail to info@contic.de (subject "Security: cf7-spamschutz"), not as a public issue.
